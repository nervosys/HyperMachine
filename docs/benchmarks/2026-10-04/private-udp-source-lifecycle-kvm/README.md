The guest agent's receiving relay owns a connected loopback UDP socket to port 18082. The fixture inventories the target's `/proc/net/udp` before launching the source client, confirms the first exact echo, and identifies exactly one newly added relay socket by its local endpoint and inode.

Source pause and source deletion each require that exact target relay socket to disappear within five seconds after the lifecycle API returns. The report retains the observed socket identities and remaining target sockets; the sets are disjoint in both phases. The total from client launch through observation must also stay below fifteen seconds, shorter than the client's twenty-second natural lifetime and the relay's thirty-second idle timeout. This rules out those natural-expiration explanations. The source's paused record is verified, and deletion leaves no source record. This observes actual relay resource teardown while the source cannot report its own traffic; it does not claim a UDP EOF signal to the source.
