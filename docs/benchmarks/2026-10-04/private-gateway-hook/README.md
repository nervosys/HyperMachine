# Private gateway routing hook

Final isolated sources pass **193 networking tests, zero failures**, and **63 daemon tests, zero failures, two ignored KVM tests**. A trusted `PrivateNetwork` builder extension classifies private DNS names and destination addresses before Internet egress policy. TCP setup pauses acceptance until the private dial succeeds. The private path directly dials its authorized transport, bypassing Internet SOCKS, protocol sniffing and header/secret interception. Refusal or timeout never falls back to the ordinary resolver/dialer. DNS answers must lie entirely within the declared private address pool; they are not remembered as ordinary egress name exceptions and have zero TTL.

Three new tests exchange real Ethernet frames with a second smoltcp guest stack, including DNS queries and TCP handshakes to an owned loopback echo target. They verify exact HTTP-looking binary bytes with Internet disabled and an unusable configured SOCKS proxy; ordinary egress remains refused. A permissive ordinary policy, reachable ordinary dialer and ordinary DNS answer cannot override private refusal. A private resolver returning an address outside its pool is refused. Existing reserved-address, DNS rebinding, SOCKS and interception tests also pass.

`net-v1.txt` passed before a duplicate builder annotation was removed; `net-v2.txt` is final. Catalog checks verify 136 permitted root/isolate source pairs and accepted isolated core hashes. Protected root core sources were neither read nor built.

This is the gateway routing mechanism with a test-only owned router. The production router must supply stable whole-pool/name classification and independently authorize membership during DNS and every dial, binding its fixed source VM lease. Atomic address allocation, daemon wiring, KVM guest-to-guest/cross-node traffic, lifecycle integration and performance measurements remain unfinished. This does not establish full private networking or competitor superiority.
