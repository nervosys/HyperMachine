# Stored browser grant admission and owner CLI

Browser credentials explicitly provisioned with `allow_owner_grants: true` may use owner-managed stored grants when their existing operator sandbox scope does not authorize a request. The flag defaults to false, preserving existing empty-scope deny-all policies. Operator scopes authorize independently: owner revocation does not revoke those scopes. Credentials and opaque identity provisioning remain operator-managed; no SSO or verified-email claim is made.

Stored admission uses an atomic sandbox/grant snapshot with a five-second timeout, validates owner/incarnation/subject and exclusive grant expiry, then reauthenticates credentials after the await. Rotation, expiry and delegation changes deny. Missing/invalid/store-error/timeout outcomes deny. Successful admission strips Basic credentials and replaces forged identity. Envd token transport and existing operator-scope checks remain unchanged. Already admitted streams retain admission.

The complete isolated cluster library passes 132 tests with one ignored; the ACL-specific test reports skipped. Deterministic admission tests hold a store lookup pending while rotating/expiring/disabling delegation, prove denial, and verify cancellation of a five-second stalled read. All 31 control-plane integrations pass. The owned TLS fixture verifies HTTP/1 and HTTP/2 stored-grant success, identity/credential handling, exact-ID exclusions, revocation, expired grants, HTTP 401/gRPC status 16 denial and unchanged backend-open counts for refusals. Its backend represents a node proxy and does not boot a guest. Existing real KVM operator-file scope evidence is separate.

The CLI supports show, replacement from a bounded JSON request file and revocation with explicit canonical expected/new revisions. Two library tests pass for strict grants, no owner override, exact file retries, bounded responses and safe errors. The binary compiles, but its first filtered run selected zero sharing tests; that log is retained and not counted as test verification. Final library-target tests execute both sharing checks.

Sources, raw logs and selected dependency hashes are preserved. Root/isolated candidate payloads match; protected isolated hashes were checked around every command. Owned Redis servers disabled disk persistence and were stopped with their temporary directories removed. This establishes local functional management/admission, not Redis restart/crash durability, real KVM owner sharing, public deployment, SSO, tenant/team isolation or competitor performance. No overall feature/performance superiority is claimed.
