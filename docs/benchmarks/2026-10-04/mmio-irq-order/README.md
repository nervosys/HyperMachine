# Serialized MMIO interrupt transitions (experimental preparation)

The old transport released its status lock before asserting a raised interrupt or deasserting an acknowledged one. An older acknowledgement could therefore deassert a line asserted by a newer packet. The candidate holds the status lock through each nonblocking sink transition, including register reset deassertion. Both deterministic concurrent tests fail against old production ordering, and pass with the fix. This establishes a transport race; causality for the observed restored-guest stall remains unproven.

Isolated regressions pass: 16 MMIO transport, 47 selected core (2 ignored), 26 vsock, 531 agent and 64 daemon (2 ignored). The initial daemon invocation incorrectly requested a nonexistent library target; the corrected binary-target invocation passed, and both logs are retained. The candidate also contains preceding experimental acknowledged-pause and per-connection progress changes.
