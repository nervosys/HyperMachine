# Membership-backed source router

`PrivateSourceRouter` binds to the source and store of its trusted connector and acquires a source lifecycle lease for each operation. It reserves `<sandbox-id>.<tag>.hv2.internal` (DNS labels, case-insensitive names, optional final dot), including unknown/malformed names within the private namespace. DNS checks current paired membership, source incarnation, live node records and HTTPS destination origin; it loads the source ledger, allocates and awaits atomic store acceptance before returning an address. Concurrent updates rebase at most four times within a five-second DNS deadline. Fresh membership and the source lease are checked again after publication. TCP loads only a committed binding, authorizes a fresh snapshot, then passes the complete claim to generation-pinned node dialing within a twenty-second total deadline.

Final suite: **114 passed, zero failed, one ignored**. New namespace and Memory/Redis router contracts cover source lease refusal before ledger creation, concurrent team/dev DNS allocation, committed returned mappings, repeated resolution, cross-owner/network and missing destination refusal, fresh addresses after rejoin, stale address refusal before transport, node disappearance and ten lease drops per backend. The driver verifies two router, two address-store and two paired-route contract markers. Owned Redis exits zero and is reaped. Redis ACL fault opt-ins remain unset.

The excluded v3 fixture incorrectly expected twelve lease drops for ten operations. v4 corrects that test-only count and passes. Catalog verifies 138 permitted root/isolate source pairs and accepted isolated core hashes. Protected root core source was neither read nor built.

The lease factory is mocked in these router fixtures. Daemon-local factory and gateway hook wiring, actual router TCP payloads, same/cross-node KVM guest-to-guest tests, address-store failure/uncertain-response tests and Redis crash durability remain unverified. Remote destination local pending-registration state is checked by receiving transport on dial, but DNS discovery does not yet query that local marker. These gaps prevent a complete private-networking claim. No performance superiority follows from this run.
