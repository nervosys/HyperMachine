# Bounded native TCP relay

The relay serves an already-bound reservation, creating one upstream stream per admitted ingress connection through a trusted connector interface. It checks TCP eligibility and exact listener/allocated-port identity before dispatch. Its task set caps concurrent connections at a configured 1–1024 per listener, bounds upstream opening to at most 60 seconds and bounds absolute connection age to at most 24 hours. These are configurable nonzero bounds, not idle timeouts or fleet-wide capacity limits. No client-supplied target or credential is accepted. An authenticated production node connector is not yet implemented.

Owned loopback ingress plus in-process duplex echo tunnels verify exact 1 MiB binary transfer, TCP half-close, live bidirectional traffic, connection-cap refusal, error/timeout/panic slot recovery, explicit shutdown, externally cancelled owner cleanup, absolute-age expiry, and reservation/listener mismatch refusal before upstream dispatch. Panic recovery evidence applies to the test profile with unwinding; a panic=abort release process terminates instead. All fixture echo tasks are owned and aborted/joined by the tests.
