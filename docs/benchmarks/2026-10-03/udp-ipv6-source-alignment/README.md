# Exact six-crate IPv6 source alignment

This audit resolves the nineteen root/isolated byte differences recorded in [the initial IPv6 forwarding evidence](../udp-ipv6-forwarding/README.md). Nine are CRLF/LF only. The other ten, all daemon helpers, produce identical Rust source after running the same rustfmt --edition 2021 --config style_edition=2024 --emit stdout command; their diffs concern layout, import ordering and return semicolons. The audit records exact before-copy hashes and formatter equality. These were byte differences, not demonstrated feature or logic changes.

The nineteen reviewed root files were copied byte-for-byte into the accepted isolated checkout. A full catalog now proves exact root/isolated equality for all Rust source/tests and Cargo manifests of hm-cli, hv2-agent, hv2-api, hv2-cluster, hv2-guest-agent and hv2-sandboxd. The root worktree files themselves were unchanged. The accepted isolated core remains unchanged; the protected root core versions were not read or executed. Root and isolated Cargo.lock still differ, so this is not a whole-root-workspace verification.

Relevant rebuilt regressions pass: 15 focused host-agent tests, 46 node tests and all 28 control-plane integration tests, including the new IPv6 key-scope fixture. API/CLI/guest implementation source is unchanged from the preceding verified run; their recorded tests remain scoped to that run. Fresh development CLI/node/control artifacts are copied to distinct immutable paths before KVM checking. The node binary hash differs from the initial formatting context; CLI/control hashes remain identical.

Two fresh API HTTPS/node mTLS/Redis/KVM stacks pass: twelve checks with eight IPv6 local peers reaching an IPv6-only guest service, and nine checks for default IPv4 compatibility. The IPv6 run preserves 1,000 exact tagged 4 KiB replies per peer, plus empty/binary/65,507-byte functional payloads. Credential, trust, protocol mismatch and malformed-frame refusals pass. Pause/resume/delete closes streams and clears inventory. Every owned service is reaped and all input hashes stay unchanged.

Reproduce the archived checker with recorded inputs, --tls --mtls and a fresh output. For IPv6 add --guest-ipv6 --local-ipv6 --peer-count 8 --concurrent-samples 1000 --concurrent-payload-bytes 4096. Build from the exact cataloged six-crate source with the recorded accepted core/lock context. The earlier archive remains an accurate record of its pre-alignment source bytes; this follow-up supersedes its unrelated-source uncertainty for these six crates.

This strengthens provenance for the implemented IPv6 tunnel. It does not prove native public UDP exposure, whole-workspace correctness, sustained performance or competitor superiority. Concurrent timings are correctness characterization, not a matched optimization experiment.
