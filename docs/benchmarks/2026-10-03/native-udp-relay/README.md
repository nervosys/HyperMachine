# Bounded native UDP relay

The native UDP relay owns one framed upstream tunnel per source socket address. It validates UDP eligibility and exact socket/reservation port before dispatch. Per-listener configuration permits 1–1024 peers, with fixed eight-frame queues, nonzero bounded opening/I/O timeouts and outbound inactivity expiry. Peer or queue pressure drops datagrams without growing those limits. Maximum payload is 65,507 bytes; an ingress buffer one byte larger detects oversized IPv6 datagrams rather than forwarding a truncated valid-size payload. Each complete frame is written in one buffer, and only the corresponding peer receives its decoded replies.

Owned IPv4/IPv6 loopback sockets and in-process framed echo tunnels verify empty/binary/maximum datagrams, concurrent distinguishable peers, third-peer cap refusal, queue pressure, oversized IPv6 ingress refusal without opening a peer, open error/timeout/panic recovery, malformed oversized/truncated upstream frames, same-peer reconnection, idle expiry, explicit shutdown, external owner cancellation and exact listener release. TCP-only and mismatched reservations never dispatch. Panic recovery applies to the unwinding test profile; panic=abort processes terminate. Tests own echo tasks in a JoinSet and relay fixtures abort on drop; successful paths abort/join remaining work.
