# Authenticated native UDP node adapter

The reservation-checked mutual-TLS node adapter now selects exact TCP or UDP routes/protocols internally. UDP requires a stored UDP/both reservation and negotiates hv2-udp/1. It retains the internal HTTP/1 client, redirect refusal, configured cluster token and node certificate trust, HTTPS-origin constraints, 15-second setup bound, and before/after reservation/lifecycle/node identity checks. Native ingress address family is independent of the guest destination: these UDP node requests select the existing IPv4 guest relay, not udp6.

Combined owned fixtures send native UDP through the bounded relay and mutual-TLS HTTP upgrade to an owned node echo stream. IPv4 and IPv6 ingress preserve empty, binary and 65,507-byte datagrams exactly. Direct adapter checks preserve early empty and binary frames attached to the upgrade response. UDP refusal checks cover wrong owner, pause, TCP-only/stale reservation, deletion and a TCP response to UDP negotiation. During setup, deletion, pause, a protocol metadata change and relocation to a different node with the same URL all refuse the stale allocation. Existing TCP tests continue to pass after sharing the transport selection logic.

Final isolated cluster library tests: 78 passed, one ignored. Control-plane integration tests: 28 passed. Optional Redis tests are not new live Redis evidence in this run. Owned fixture tasks abort on drop; successful tests await their termination, and native relay shutdown joins peer tasks. Source snapshots and exact logs are hashed in manifest.json. Builds ran only in `/var/tmp/hm-egress-log-mA2CCL` with accepted core hashes and byte-aligned current module/export sources. Protected root core files were not read or built.

These checks prove fixture-level authenticated native datagram delivery, not delivery to a real guest or over the Internet. Running gateway/relay reconciliation, aggregate host budgets, owner-specific management, service restart and guest reboot behavior remain incomplete. No public-service parity or performance win is claimed.
