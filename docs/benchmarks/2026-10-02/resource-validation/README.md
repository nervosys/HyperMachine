# Resource validation after timed batches

All 32 real restores passed at concurrency 8 with the accepted executable and matched Firecracker inputs. Every successful child verifies one CPU and 1,024 MiB after all peer timers stop. This is a measurement-method correction, not a runtime performance improvement. Previous frozen results retain their original coordinator.

A separate four-guest fault study falsifies only post-timing resource GET responses to report 512 MiB. Both engines correctly fail all samples, while every owned guest and process is cleaned up. Fault timings are excluded from rankings. The analyzer rejects missing, mismatched, boolean, or incorrectly phased resource evidence and preserves legacy report compatibility.
