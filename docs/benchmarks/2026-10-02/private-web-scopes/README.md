# Sandbox-scoped private guest URLs

The final run passed 25/25 functional cases with real nested KVM, control-plane API/proxy TLS and node mTLS. The new sharing case verified exact-ID grants, fork exclusion, custom-domain restrictions, scope revocation, refusal without waking an out-of-scope paused auto-resume guest, invalid-scope reload preservation, an empty deny-all scope, and a rebound domain using its current target ID. Existing browser login, identity substitution, credential stripping, cache policy, credential rotation, SSH, TCP, role restrictions and lifecycle checks passed again.

Linux and Windows each passed all 46 library tests and 26 HTTP integration tests. The latter verify denied custom-domain and explicit routing-header requests over both HTTP/1 and HTTP/2 without opening a backend route, as well as allowed access, revocation and deny-all behavior. Strict cluster library/test Clippy passed on both platforms with the existing `too_many_arguments` exception. No API proxy implementation changed in this extension.

The release control-plane binary is SHA256 `36b8ea68a677c2746eb864af0b72ee8820b9281ff6c9e2b45344e5664118e769`. The clean build extends the previous private-web implementation with the frozen scope sources; all eight relevant source inputs match the working tree. The three provisional core boot/backend changes were excluded. The accepted daemon, CLI, kernel and initrd are unchanged and identified by hashes in the report. All seven fixture input hashes match before and after the run. Cleanup left zero sandboxes and stopped all 22 registered processes. Independent verification checked 188 API audit MAC records with zero incomplete admissions; guest web requests are not audited by this feature.

A policy can grant exact sandbox IDs, all IDs with `["*"]`, or no IDs with `[]`. Omitted scopes retain the originally documented all-sandbox behavior. Policy replacement changes grants atomically for new requests; admitted streams retain their original admission. This is operator-managed web sharing, not SSO/OIDC, verified email, self-service sharing, or API/exec/SSH authorization. Read [configuration and limits](../../../PRIVATE_GUEST_URLS.md).

This is functional local nested-KVM evidence. No authentication throughput, startup improvement or managed competitor win is claimed. Verify the archive with `python tools/verify-private-web.py docs/benchmarks/2026-10-02/private-web-scopes --require-scopes`.
