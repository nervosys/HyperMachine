# Private guest URLs with operator browser login

The final run passed 24/24 functional cases using a real nested KVM guest, a TLS control-plane API and web proxy, and node mTLS. Four new cases verify browser Basic login with a dedicated credential, policy-sourced guest identity and credential stripping, custom-domain access, refusal without resuming a paused auto-resume guest, and SIGHUP rotation/rejected replacement/expiry. Startup without proxy TLS and node mTLS was refused. The HTTP response was forced to `private, no-store`. The remaining cases exercise existing SSH, TCP, role restrictions and lifecycle behavior.

Linux and Windows each passed 45 library tests and 26 HTTP integration tests. Linux also passed all nine existing proxy tests. Strict cluster/API Clippy passed with the existing `too_many_arguments` exception. The first Linux lint run failed on a missing semicolon in the Unix reload branch; its log is retained. The fixed release binary is SHA256 `3acfd4e3a645888efeb2165ba031d94600f720f060f7fb36889c3afc37aa0280`.

The daemon, CLI, kernel and SSH fixture are unchanged accepted inputs, identified in the report. The control-plane build uses the clean c01de88 source baseline plus the frozen relevant source files in this archive. The three provisional core boot/backend changes in the working tree were excluded. All seven fixture inputs had identical hashes before and after the run. Cleanup left zero sandboxes and stopped all 22 registered processes. Independent API audit verification checked 172 MAC records with zero incomplete admissions; guest web requests are not audited by this feature.

This is opt-in, operator-provisioned access to all guest application URLs behind the configured proxy. Identity is an opaque operator-assigned subject, not a verified email claim. SSO/OIDC, individual sandbox sharing permissions, account self-service and browser logout remain incomplete. Basic credentials must be random high-entropy values delivered separately to each user. Alternate public proxies must be protected consistently. Read [configuration and limits](../../../PRIVATE_GUEST_URLS.md).

This archive contains functional evidence only. It establishes no performance advantage or managed-vendor win. Run `python tools/verify-private-web.py docs/benchmarks/2026-10-02/private-web` to verify file hashes, required cases, unchanged artifacts and cleanup.
